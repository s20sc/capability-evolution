# Action-mean drift selection

The JSON contains all nine saved per-step drift arrays, exact tail scores and the fixed three selected scenes. The source excerpts identify the original procedures for common observation histories, recurrent resets, analytic GMM means, normalized RMS drift, upper-tail aggregation and ranking.

These excerpts are not a standalone neural-execution entry. Saved-array reaggregation checks the scores and ranking; it does not independently regenerate neural predictions or establish physical task outcomes. Full learned-state and trajectory inputs retain the separate companion and runtime requirements documented in the study guides.
